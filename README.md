# Aplikacja
Aplikacja do kontrolowania gwarancji zakupionych urządzeń domowych

Aplikacja jest dla osób, które mają wiele sprzętów i chcą sobie ułatwić kontrolowanie okresów gwarancji.

Zespół:
- Weronika Zielińska dsw58966
- Danyl Takiullin Pro100D

Technologia:


Funkcjonalności: 
1.Zarządzanie kategoriami urządzeń
-  logowanie się do konta i wylogowanie się
-  tworzenie kategorii sprzętów, np. "AGD kuchnia", "AGD łazienka", "Elektonika"
-  przypisywanie sprzętów do odpowiednich kategorii
-  przeglądanie sprzętów według kategorii
-  edytowanie u usuwanie kategorii
2.Zarządzanie urządzeniami
- dodawanie nowego urządzenia do aplikacji
- dodanie nazwy urządzenia
- dodanie opisu urządzenia
- przypisanie urządzenia do wybranej kategorii
- wprowadzenie daty zakończenia gwarancji
- edytowanie informacji o urządzeniu
- usuwanie urządzenia
- dodanie zdjęcia paragonu
3.Wyszukiwanie i filtrowanie urządzeń
- wyszukiwanie urzadzenia na podtawie nazwy
- wyszukiwanie urzędzenia za pomocą opisu
- wyświetlanie wyników wyszukiwania
- filtrowanie sprzętów według kategorii
